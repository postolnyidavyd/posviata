# Пульт ведучого «Посвята в ІТшника»

Веб-пульт для командного івенту (3 команди: Mac / Linux / Windows).
Node.js + WebSocket на бекенді, React (Vite) на фронті, стан in-memory + снапшот у файл.

Повне ТЗ — у `posvyata-pult-tz.md`.

## Ролі (за URL)

| Роль | URL | Що бачить |
|---|---|---|
| Ведучий | `/host?key=СЕКРЕТ` | повний стан + керування |
| Проектор | `/screen` | повний стан, тільки перегляд, крупно |
| Команда | `/team?team=0` (0=Mac, 1=Linux, 2=Windows) | урізаний стан, тільки відповідає |

Ключ ведучого задається змінною `HOST_KEY`.

## Запуск локально (розробка)

Потрібні **два** процеси (в різних терміналах):

```bash
# 1. бекенд (WS + стан) на :3001
npm install
HOST_KEY=testkey npm run dev:server        # PowerShell: $env:HOST_KEY="testkey"; npm run dev:server

# 2. фронт (Vite) на :5173
npm run dev:client
```

Відкрити:
- `http://localhost:5173/host?key=testkey`
- `http://localhost:5173/screen`
- `http://localhost:5173/team?team=0`

У dev-режимі фронт сам конектиться до WS на `:3001`.

## Запуск як прод (один процес)

```bash
npm install
npm run build      # збирає client -> client/dist
HOST_KEY=секрет npm start
```

Сервер віддає і статику, і WS на одному порту (`PORT`, дефолт 3001).
Відкрити `http://localhost:3001/host?key=секрет` тощо.

## Деплой на Railway

1. Створити проєкт з цього репозиторію.
2. Railway сам зробить `npm install` → `npm run build` → `npm start`.
3. У **Variables** задати:
   - `HOST_KEY` — секрет ведучого (обов'язково зміни!)
   - (опційно) `ROOM_ID`, `SNAPSHOT_FILE`
   - `PORT` Railway підставляє автоматично.
4. WS працює через той самий домен (`wss://…`) — окремо нічого налаштовувати не треба.

> Снапшот стану пишеться у файл (`state.json`). На Railway файлова система ефемерна —
> для збереження балів між рестартами підключи **Volume** і вкажи `SNAPSHOT_FILE`
> на шлях усередині volume. Без volume бали переживуть реконект, але не редеплой.

## Конфіг (усі тюнабельні числа)

`server/config.js` — бали за місце, штраф за помилку Keyboard, стеля ставки фіналу,
пресети таймера, назви команд. Секрети — через `.env` (див. `.env.example`).

## Що готово

- Скелет: WS-сервер, `Room`, ролі, **серверна** фільтрація стану, снапшот, реконект
- Наскрізне: табло балів (ручні +/−, кнопки «за місце»), таймер (на таблі — лише під час івента)
- Режим **Keyboard Battle**: еталон, старт, збір часу+тексту, підрахунок помилок по словах
  (макс 1 на слово) з підсвіткою, ручна корекція, ранжування, нарахування 3/2/1
- Режим **Колесо розподілу**: вводиш кількість учасників → крутиш → колесо зупиняється на команді
  й **авто-зараховує**; розподіл рівний (різниця максимум 1); анімація на екрані й у команд
- Режим **Слово** (Paint / Поясни / Хто я?): банки слів, слово тільки в host, плейсхолдер+таймер решті
- Режим **Фінал на ставках**: ставки 1..min(3, рахунок), single + відкриті питання,
  reveal, авто-суд варіантів / ручний суд відкритих, нарахування +/−ставки

Банки контенту (слова, терміни, фінальні питання) — у `server/banks.js`, наповнені простими
загальновідомими речами під першокурсників. Редагуй/додавай прямо там.
